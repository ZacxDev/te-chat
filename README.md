# How To Run

- The project is staticly compiled and checked in to make it easy to run without installing a builder, simply serve the `public` directory (ex `python -m http.server 8000 --directory public`)
- Alternatively you can install `go-static-site` to run the project with the framework it was built with

```
go get -u https://github.com/ZacxDev/go-static-site
```

- Install npm modules with `npm i`
- Then run with `go-static-site serve`
